# WhSnap — Windows 截图贴图工具 项目规划方案（对标 Snipaste）

> 版本：**v4.1**（已进入执行阶段；预览版 v0.1.0-preview.1 已交付，见 §10.5）
> 定位：Windows 平台对标 Snipaste 的「截图 + 贴图」工具
> 团队：**1 人全职** | 主用系统：**Windows 11** | 分发：**仅安装包**（无便携版）
> 发布对象：**自己 + 小圈子**（非公开分发）
> 已定决策：核心 = 截图 / 贴图 / 快捷键设置（冲突检测）/ 安装包；**不含 OCR**；**自签名证书（零付费，小圈子分发足够）**；安装后默认开机自启；**功能尽量开放给用户自行设置**

## 2. 范围与验收

### 2.1 v1.0 功能清单

**A. 截图（核心）**
- 全局热键唤起 → 冻结屏幕 → 全屏遮罩选区
- 8 向手柄、像素级微调（方向键 1px / Shift 10px / Ctrl 改锚点）
- 放大镜：像素网格 + 实时坐标 + 色值（最近邻放大，不模糊）
- 多屏 + 混合 DPI + 竖屏旋转正确
- **自动检测窗口/界面元素区域**（UIA + 窗口矩形回退，Tab 切换）
- 确认后三选一热键直达：进剪贴板 / 快捷保存 / 直接贴图
- 取色器（HEX/RGB/HSL/CMYK + 颜色历史）

**B. 贴图（核心）**
- 分层置顶无边框窗口，逐像素 alpha
- 滚轮缩放、`Ctrl`+滚轮透明度、`1/2` 旋转、`3/4` 翻转、双击隐藏、`Shift`+双击缩略图、鼠标穿透、拖放文件即贴
- 从剪贴板贴图：图像 / 纯文本 / HTML / 颜色值 / 图片文件（PNG/JPG/BMP/ICO）
- 贴图内标注（空格键）、`Alt` 取色
- 自动备份 + 崩溃/重启恢复、显示器拓扑变化后位置重算
- 贴图数量与层级管理面板

**C. 快捷键设置与冲突检测（核心）** — 详见 §5.7
- 全部动作热键可自定义；三层冲突检测；导入导出；恢复默认

**D. 安装包（核心）** — 详见 §10
- Inno Setup、per-user 安装（免 UAC）、默认开机自启、干净卸载、静默参数
- 自签名 + 时间戳、自动更新、崩溃转储收集

**E. 标注（全量对齐 Snipaste）**
- 矩形、椭圆、直线、箭头、铅笔、马克笔、文字
- 马赛克、高斯模糊、橡皮擦、序号、高亮
- 撤销 / 重做、图元可选中后二次编辑（移动/缩放/改样式）
- 导出严格物理像素 1:1

**F. 设置（全配置化）** — 详见 §6
- 覆盖 A–E 全部可调行为 + 高级/实验性开关 + JSON 手工编辑 + 导入导出

### 2.2 量化验收指标（v1.0 门槛）

| 指标 | 目标 | 测量 |
|---|---|---|
| 热键 → 遮罩可交互 | ≤ 200 ms | 埋点中位值 |
| 遮罩内鼠标跟随延迟 | ≤ 16 ms | 帧时间统计 |
| 确认 → 剪贴板可粘贴（4K 单屏） | ≤ 400 ms | PNG 编码计入 |
| 常驻内存（无贴图） | ≤ 120 MB | 私有工作集 |
| 30 张贴图常驻 | ≤ 250 MB | 同上 |
| 冷启动到托盘就绪 | ≤ 1.5 s | 冷启动计时 |
| 混合 DPI 双屏（100%+150%）选区错位 | 0 px | 100 次回归 |
| 热键冲突检测 | 已占用热键 100% 判为冲突 | 对已知占用键做用例 |
| 崩溃率 | < 0.1% 会话 | 本地 dump 统计 |

### 2.3 明确不做（写死边界）
录屏/GIF 录制、云同步与账号、在线图床上传、PDF/文档标注、Win7/8 兼容、macOS/Linux、**OCR**、**进程注入**、便携模式。

## 3. 对标 Snipaste 的差距管理

对标一个免费、成熟近 10 年的工具，**功能数量不可能赢**，所以把话说透：

| Snipaste 能力 | WhSnap | 计划 |
|---|---|---|
| 区域/全屏/元素检测截图 | ✅ v1.0 | — |
| 像素级控制、取色器 | ✅ v1.0 | — |
| 历史记录回放 | ❌ v1.1 | 优先级中（自用价值其实不低，可提前） |
| 标注全量工具 + 撤销重做 | ✅ v1.0 | — |
| 贴图缩放/旋转/翻转/透明/穿透/缩略图/隐藏 | ✅ v1.0 | — |
| 剪贴板文本/HTML/颜色/文件转贴图 | ✅ v1.0 | — |
| 贴图自动备份恢复 | ✅ v1.0 | — |
| 多屏 + 高 DPI | ✅ v1.0 | — |
| **贴图分组** | ❌ v1.1 | 优先级中 |
| **GIF 动图贴图（含帧步进）** | ❌ v1.1 | 需 WIC/GIF 解码，工作量不小 |
| **主题色/界面字体深度自定义** | ⚠️ 部分 | 浅色/深色 + 主色可调 |
| **跨平台（Mac/Linux）** | ❌ 不做 | 本项目定位 Windows |

**WhSnap 的立足点（靠这三条，而不是靠功能数）**
1. **Win11 原生与轻量**：不装驱动、不注入进程、不后台联网，启动与内存优于竞品。
2. **设置的开放度**：做到"想调的都能调"，见 §6。
3. **自用打磨**：单人项目的真实优势是"我天天用，我知道哪里别扭"。第 11 周起强制狗粮，把这些别扭逐个磨掉。

> 关键判断：**发布对象是自己 + 小圈子**，意味着评判标准不是"功能比 Snipaste 多"，而是"我和朋友用一周后不想换回去"。这把优先级从"堆功能"改成"打磨手感 + 稳定"，也支持 §7 里"对标收尾减半"的排期建议。

## 4. 技术选型

| 层次 | 选型 | 理由 |
|---|---|---|
| 语言/运行时 | **C# 12 / .NET 8（LTS）**，`net8.0-windows10.0.19041.0` | 单人开发效率优先；P/Invoke + CsWinRT 齐备 |
| UI | **WPF**（设置/托盘）+ Win32 顶层窗口（遮罩、贴图） | 遮罩与贴图必须是原生无边框顶层窗口 |
| 采集 | 主：**Windows.Graphics.Capture**；备：**DXGI Desktop Duplication**；兜底：GDI `BitBlt` | Win11 上 WGC 覆盖更全；DXGI 帧更稳 |
| 渲染 | V1：WPF `DrawingVisual` + `RenderTargetBitmap`（物理像素 1:1）；贴图：`UpdateLayeredWindow` | 先出功能，4K 帧时间不达标再下沉 Direct2D |
| 元素检测 | UI Automation + `EnumWindows` + `DWMWA_EXTENDED_FRAME_BOUNDS` | 准确率递降回退 |
| 配置/日志 | JSON + Serilog；崩溃转储 WER LocalDumps | 本地优先，默认不联网 |
| 打包 | **Inno Setup**（per-user）+ 自研 JSON 更新清单 | 免 UAC，更新链简单 |
| 签名 | **自签名代码签名证书** + RFC3161 免费时间戳 | 零成本，小圈子分发足够（见 §10.2） |
| 测试 | xUnit + 图像像素断言 + 真机矩阵 | 多屏/DPI 必须自动化回归 |
| CI | GitHub Actions `windows-latest`：构建/单测/打包/签名 | 构建可复现是过杀软误报的前提 |

**命名规约**：解决方案 `WhSnap.sln`；命名空间 `WhSnap.App` / `.Presentation` / `.Application` / `.Domain` / `.Platform`；程序集 `WhSnap.exe`；产物 `WhSnap-setup-x64.exe`；单实例互斥体 `WhSnap_SingleInstance`；配置目录 `%APPDATA%\WhSnap`；安装目录 `%LOCALAPPDATA%\Programs\WhSnap`。

## 5. 架构与关键技术方案

### 5.1 分层

```
┌──────────────────────────────────────────────────────────┐
│ Presentation                                             │
│  TrayHost │ SettingsWindow(快捷键/外观/行为/高级) │        │
│  OverlayWindow │ PinWindow │ ColorPickerWindow │ Toast   │
├──────────────────────────────────────────────────────────┤
│ Application（用例编排 + 命令总线）                         │
│  CaptureSession │ PinManager │ HotkeyService │           │
│  ClipboardService │ ConfigService │ UpdateService │      │
│  AnnotationService │ HistoryService                      │
├──────────────────────────────────────────────────────────┤
│ Domain（纯逻辑，可单测）                                   │
│  Geometry(物理像素) │ AnnotationModel(图元+命令栈) │       │
│  SelectionModel │ ColorModel │ PinState │ HotkeyModel │  │
│  SettingsSchema                                          │
├──────────────────────────────────────────────────────────┤
│ Platform（全部 P/Invoke 集中于此）                         │
│  ScreenCapture(WGC/DXGI/GDI) │ ScreenTopology │          │
│  LayeredWindow │ GlobalHotkey │ Clipboard │ UIA │ Input  │
│  AutoStart │ Dpi │ PowerEvents                           │
└──────────────────────────────────────────────────────────┘
```

**三条不可违反的约束**
1. **坐标一律物理像素**贯穿 Domain；DIP 只在 UI 布局时转换。
2. **View 不直接 P/Invoke**，平台调用全走 Platform 层。
3. **一次截图 = 不可变底图 + 图元列表**；标注是叠加数据，导出时 1:1 合成，撤销即命令栈重放。

**线程**：UI 主线程（托盘/设置）+ Overlay 独立消息循环 + 采集/编码线程 + 热键 message-only 窗口线程。

### 5.2 屏幕采集（三路可切换）
WGC 为主（Win11 覆盖分层/叠加内容更好）、DXGI 为辅（帧率稳）、GDI 兜底。抽象为 `IScreenCapture`，设置里可手动指定后端；抓帧失败/黑帧自动降级并记录日志。"是否含鼠标指针"可配置。

### 5.3 冻结屏幕（体验分水岭）
热键触发即抓取**整个虚拟桌面**为静态底图并冻结：动态内容不干扰、跟随延迟只看渲染、数据源唯一稳定。多屏 4K 用共享 GPU 纹理/按屏按需拷贝控制内存峰值；分辨率变更、显示器热插拔、锁屏立即取消会话。

### 5.4 多屏 + 高 DPI + 旋转 + HDR
- 清单声明 **Per-Monitor DPI Awareness V2**。
- `ScreenTopology` 维护物理矩形、DPI、缩放比、旋转角、HDR 标志，监听 `WM_DISPLAYCHANGE` / `WM_DPICHANGED` 增量更新。
- **每显示器一个遮罩窗口**（非大窗口跨屏），鼠标所在屏为活动屏，其余压暗。
- HDR 转 sRGB 需色调映射，否则截图偏灰；提供"保持原始位深另存"选项。

### 5.5 遮罩交互
`WS_POPUP` + `WS_EX_TOOLWINDOW` + 置顶，不占 Alt+Tab。全键盘可达：方向键微调、`Shift` 加速、`Ctrl` 改锚点、`Enter` 确认、`Esc`/右键取消、`Tab` 切元素检测、`C` 取色、`F3` 直接贴图。

### 5.6 标注引擎
- 图元模型 `{类型, 几何(物理像素), 样式, Z序, 元数据}`；命令栈撤销（非位图快照，省内存且支持二次编辑）。
- 马赛克/高斯模糊为独立图元，**不破坏底图**，可事后调整块大小/强度。
- 文字支持 CJK + Emoji + IME 输入法，处理换行/对齐/描边/背景色。
- 导出只走物理像素路径，任何 DPI 缩放不允许出现在导出链路。

### 5.7 快捷键设置与冲突检测（核心功能，方案细化）

**数据模型**：`HotkeyBinding { ActionId, Modifiers, VirtualKey, Enabled, Scope }`；`Scope` 区分**全局热键**（`RegisterHotKey`）与**应用内热键**（遮罩/贴图窗口内的键，如 Enter/Esc/数字旋转）。

**注册机制**
- `RegisterHotKey` + `MOD_NOREPEAT`（防长按洪水），句柄挂在 message-only 窗口。
- 允许无修饰键的键（PrtScn、F1）；`Win` 组合需处理系统保留键。
- 每个热键独立记录状态：`Registered / ConflictWithSystem / Invalid / Disabled`。
- **唤醒重注册**：监听 `WM_POWERBROADCAST`，休眠恢复后自动重注册（不处理会静默失效）。
- **降级路径**：用户坚持用被系统占用的组合键时，可切低级键盘钩子 `WH_KEYBOARD_LL`（默认关闭、风险提示、不注入进程）。

**三层冲突检测（本功能交付重点）**

| 层 | 内容 | 实现 | 提示 |
|---|---|---|---|
| L1 系统占用 | 是否已被系统/其他软件注册 | 临时隐藏窗口**试注册**，成功=可用，失败=已占用 | 红色标记 + "已被占用" |
| L2 内部重复 | 与已配置的其它动作撞键 | 修饰键排序规范化后比对 | 指出撞了哪个动作，禁止保存 |
| L3 常见冲突源 | 占用者身份**无法枚举**（Windows 无公开反查 API） | 内置已知冲突源库做启发式提示 | "最可能被 X 占用" + 排查指引 |

**L3 冲突源库（Win11，随版本维护）**：`Win+Shift+S`（系统截图，第三方无法抢占）、`PrtScn`（Win11 设置里可改为打开截图工具，需检测）、`Win+PrtScn`、`Win+G`/`Win+Alt+PrtScn`（Xbox Game Bar）、输入法 `Ctrl+Space`/`Shift`、微信/QQ `Alt+A`、钉钉/飞书/企业微信截图键、`Alt+Z`/`Alt+F9`（NVIDIA）、PowerToys 快捷键、Snipaste 默认 `F1`/`F3`、笔记本 Fn 组合键。

**UI/UX**
- 录制控件：点击进入捕获态、实时显示键位、仅修饰键或非法组合内联提示、`Esc` 取消。
- 每行显示：当前键位 + 状态徽标 + 冲突原因 + 单行恢复默认。
- **冲突策略**：默认**阻断保存**并高亮；提供"仍保存但禁用该热键"的显式选择，绝不静默失败。
- 保存前对**全部绑定**做 L1+L2 全量预检；导入配置同样校验并报告失效项。
- 保留键黑名单提示：`Ctrl+Alt+Del`、`Win+L`、`Alt+Tab`、`Alt+F4`。

### 5.8 剪贴板
写出多格式并写：`CF_DIBV5` / `CF_DIB` / 自定义 `PNG`（Office/浏览器识别更好）/ `CF_HDROP`。读入用 `AddClipboardFormatListener`（非轮询），支持图像/文本/HTML/颜色值/图片文件。

### 5.9 保存与导出
快捷保存（不弹框存默认目录，文件名模板如 `{yyyyMMdd_HHmmss}_{w}x{h}`，模板本身可配置）+ 另存为；PNG 默认，另支持 JPG（质量可调）/BMP/WebP；"复制到剪贴板同时保存"组合开关；保存后通知可点击打开目录。

## 6. 全配置化设计（D8 落地）

**四条原则**
1. **能配的就给 UI 入口**：不留"只有改 JSON 才能调"的隐藏项（除明确标注的"实验性"）。
2. **即时生效**：能动态生效的必须即时生效；不能的（如需重建窗口/后端）在界面上标"重启后生效"。
3. **配置即文件**：`%APPDATA%\WhSnap\settings.json`，带 `schemaVersion`，升级自动迁移；界面提供"打开配置目录"与"复制当前配置到剪贴板"（便于备份/求助）。
4. **单项重置 + 全部重置 + 导入导出**，导入时做校验并报告无效项。

## 10. 安装包、自签名与分发（核心功能）

### 10.1 安装包（Inno Setup）
- **per-user 安装**到 `%LOCALAPPDATA%\Programs\WhSnap`：**免 UAC**、更新无需提权、卸载干净。
- **默认勾选开机自启**（D7）：写入 `HKCU\...\Run`（per-user 无需提权）。
- 可选项：桌面图标、开始菜单。
- 静默安装 `/VERYSILENT /SUPPRESSMSGBOXES`；卸载清理自启项、快捷方式、缓存（配置与日志可选保留并询问）。
- **自启自检**：安全软件/优化工具常删启动项。每次启动校验注册表与配置是否一致，不一致则提示"开机自启已被移除，是否恢复"（不静默重写，尊重用户）。
- 首次运行引导：热键确认 + 自启状态确认 + 采集后端选择，一次问完。

### 10.2 自签名证书（D6）——小圈子场景下的定位与局限

**结论先行**：发布对象是**自己 + 小圈子**，自签名是**完全足够的正确选择**，不需要为此花任何钱。

**必须写明的事实**
- 自签名证书**不会**消除 SmartScreen 的"Windows 已保护你的电脑"提示，**也基本不会降低杀软误报**。
- 它的实际收益：① 文件属性页显示"发布者"名称；② 小圈子成员把 `.cer` 导入"受信任的根证书颁发机构"后，UAC 与属性页不再显示"未知发布者"；③ 签名 + 时间戳证明文件未被篡改，且证书过期后签名仍有效。
- 因为分发对象是你认识的人，**一次性的"信任导入"操作是可接受的成本**；如果将来要面向陌生人分发，才需要重新评估 OV/EV 证书（约 200–500 美元/年）。

**落地步骤**
1. 生成证书：
   `New-SelfSignedCertificate -Type CodeSigningCert -Subject "CN=WhSnap" -KeyUsage DigitalSignature -CertStoreLocation Cert:\CurrentUser\My -NotAfter (Get-Date).AddYears(5)`
2. 导出 `.cer`（公钥，随包分发）与 `.pfx`（含私钥，**本地保管、绝不入库**；`.gitignore` 必须包含）。
3. 签名：
   `signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 /f cert.pfx /p <pwd> WhSnap.exe` —— **务必加 RFC3161 时间戳**。
4. 安装包与主程序**都**要签名（先签主程序，再签安装器）。
5. 随包附 `install-trust.ps1`：管理员运行，把 `.cer` 导入"受信任的根证书颁发机构"与"受信任的发布者"。
6. CI 中脚本化签名；私钥用 GitHub Actions Secrets 注入，构建日志禁止打印口令。

### 10.3 自动更新
启动后异步拉取 HTTPS JSON 清单（版本、下载地址、SHA-256、更新日志）→ 校验签名 → 下载到临时目录 → 重启替换（per-user 免提权）→ 失败回滚。设置提供"检查更新"手动入口与更新通道（稳定/测试）；提供"永不检查"开关。
