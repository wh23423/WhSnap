## 5. 关键约束（接手时不要踩）

1. **坐标一律物理像素**；DIP 只在 WPF 布局时换算（ADR 0002）。
2. **P/Invoke 全部集中在 `Interop/NativeMethods*.cs`**，业务代码不直接 DllImport。
3. **贴图窗口是原生分层窗口**（`UpdateLayeredWindow`），不要换成 WPF `AllowsTransparency`（ADR 0003）。
4. **单一数据源**：动作只在 `HotkeyCatalog`、配置项只在 `SettingsSchema` 声明；
   `--selftest` 会校验"表 ↔ 实现"双向一致，加功能时别绕过。
5. **橡皮擦只擦标注层**，底图不能被打洞；**马赛克/模糊作用于当前可见画面**。
6. **不要用 PowerShell 的 `Set-Content`/`Out-File` 写源码文件**：本机 Windows PowerShell 会按 ANSI 写出，
   已因此把 `SelfTestRunner.cs` 写坏过一次（UTF-8 → GBK → 乱码）。改文件请用编辑器/IDE 或
   .NET 的 `File.WriteAllText` + `UTF8Encoding(false)`。
7. **异步代码不要在被阻塞的 WPF UI 线程上等待**：`--update-test` 曾因 `async` 方法 +
   `GetAwaiter().GetResult()` 在 UI 线程上**静默挂死**（进程不崩、不报错、一直等）。
   现在 `UpdateService` 所有 `await` 都带 `ConfigureAwait(false)`，且该自检整体跑在线程池上；
   以后给自检命令加异步逻辑时照此处理。

```powershell
cd D:\desktop\WHocr        # 规划方案附录里提到，会话结束后可把目录改名成 WhSnap

# 然后按 §4 继续（第 4 项：诊断包导出）
```

```powershell

# 产物：artifacts\installer\WhSnap-<版本>-setup-x64.exe（脚本会先清掉旧版本安装包）
```
