# WhSnap 用户手册

> 适用版本：**1.0.0-preview.3**（[签名版已发布](https://github.com/wh23423/WhSnap/releases/latest)）
> ｜ Windows 11，最低 10.0.22000 ｜ 对标 Snipaste 的 Windows 截图 / 贴图工具
>
> 本手册里的名称都取自程序本体：快捷键与「设置 → 快捷键」页的动作名一致，
> 配置项与「设置」窗口里的分组/标签一致，菜单与托盘/贴图右键菜单逐项对应。

## 0. 一分钟上手

| 想做的事 | 怎么按 |
|---|---|
| 截一块区域 | `Ctrl+Shift+A` → 拖动框选 → `Enter`（按设置复制+保存） |
| 只复制 / 只保存 / 只贴图 | 框选后 `Ctrl+C` / `Ctrl+S` / `F3` |
| 截一个正方形 | 框选时按住 `Shift` |
| 把剪贴板内容贴到屏幕上 | `Ctrl+Alt+Z` |
| 打开设置 | `Ctrl+Shift+,` 或托盘「设置…」 |
| 贴图缩放 / 透明 / 隐藏 | 贴图上：滚轮缩放、`Ctrl+滚轮` 调不透明度、双击隐藏、右键出菜单 |
| 出问题了给我证据 | 托盘「导出诊断包…」 |

## 1. 安装

### 1.1 系统要求

- Windows 11（内部版本 22000 及以上）。Windows 10 未做验证。
- x64。**不需要管理员权限**：安装到 `%LOCALAPPDATA%\Programs\WhSnap`。

### 1.2 安装步骤

1. 双击 `WhSnap-<版本>-setup-x64.exe`。
2. 安装向导里默认勾选 **开机自动启动**（写 `HKCU\...\Run`，只对当前用户生效）与 **创建桌面快捷方式**；不需要可以取消。
3. 装完可勾选「立即运行 WhSnap」。程序启动后**只在托盘**（右下角通知区域）出现图标，没有主窗口。

只想静默装（脚本/批量）：

```powershell
.\WhSnap-1.0.0-preview.3-setup-x64.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
```

安装日志在 `%TEMP%\Setup Log *.txt`，装完有异常先看它。

### 1.3 SmartScreen 提示「Windows 已保护你的电脑」

这是 Windows 对**未购买代码签名证书**的程序的一贯提示，不是"发现病毒"。当前 preview 包用的是**自签名**证书
（如果构建时没配签名 secret，就是完全未签名），所以：

1. 点提示里的 **更多信息**；
2. 点 **仍要运行**。

如果连"更多信息"都没有（策略更严的机器），右键安装包 → 属性 → 勾选 **解除锁定** → 确定，再运行。

### 1.4 （可选）导入信任，让发布者显示为 WhSnap

每台机器做一次，需要管理员权限（只影响"发布者是谁"的显示，不会让杀软误报消失）。
`WhSnap.cer` 与 `install-trust.ps1` 都在发布页的同一批下载里：

```powershell
powershell -ExecutionPolicy Bypass -File install-trust.ps1 -CerPath .\WhSnap.cer
```

导入后安装包属性页会显示发布者名称（`CN=WhSnap`），也不再提示「未知发布者」。
注意：**卸载程序 `unins000.exe` 是安装时现场生成的，没有签名**（卸载时可能仍显示「未知发布者」，属正常）。

### 1.5 升级

直接运行新版本安装包即可：**就地覆盖**（沿用上次的安装目录，向导不再询问目录），
配置、日志、颜色历史、贴图备份都保留在 `%APPDATA%\WhSnap`，安装包不碰它们。
安装/升级前会**自动关闭正在运行的 WhSnap**。

程序内也能升级：托盘「检查更新…」或 设置 → 维护 → 「检查更新」。

### 1.6 文件都在哪

| 位置 | 内容 |
|---|---|
| `%LOCALAPPDATA%\Programs\WhSnap\` | 程序本体与 `unins000.exe`（卸载器） |
| `%APPDATA%\WhSnap\settings.json` | 全部设置（纯 JSON，可直接编辑后重启；也可在设置里导入/导出） |
| `%APPDATA%\WhSnap\logs\whsnap-<日期>.log` | 运行日志 |
| `%APPDATA%\WhSnap\pins\<时间戳>\` | 贴图自动备份（`manifest.json` + `pin-000.png`…） |
| `%APPDATA%\WhSnap\diagnostics\` | 你导出的诊断包 zip |
| `%APPDATA%\WhSnap\dumps\` | 崩溃证据（`crash-<时间戳>.txt` + `.dmp`），最多 5 份 |
| `%APPDATA%\WhSnap\performance.json` | 性能埋点样本（四项指标） |

托盘的「打开保存目录 / 打开贴图备份目录 / 打开配置目录」可以直接跳过去。

## 2. 快捷键总表

所有键位都能在 **设置 → 快捷键** 里改。四个作用域**互不冲突**：

- **全局热键**（6 个）向系统注册，会和别的软件抢键 —— 冲突时设置页会显示「冲突」并给出处理建议；
- **遮罩内按键**、**标注内按键**、**贴图窗口内按键**只在对应窗口里生效，**不会和别的软件冲突**。

### 2.1 全局热键（默认值）

| 按键 | 动作 | 说明 |
|---|---|---|
| `Ctrl+Shift+A` | 截图（区域） | 唤起遮罩框选 |
| `Ctrl+Alt+Z` | 贴图剪贴板内容 | 把剪贴板里的图像/文件/文本/颜色值贴到屏幕上 |
| `Shift+F3` | 显示 / 隐藏全部贴图 | 收起来但不关闭 |
| （未绑定） | 关闭全部贴图 | 默认不绑定，避免误触；可自行设置 |
| （未绑定） | 打开贴图管理面板 | 同上 |
| `Ctrl+Shift+,` | 打开设置 | |

> `Shift+F3` 在本机**实测已被占用**（同机装着 Snipaste 时会撞键，设置页会显示「冲突」并给出疑似占用者）；
> 这种情况直接从托盘菜单点「显示全部贴图 / 隐藏全部贴图」一样可用，或在设置里给它换一个组合。

> **从旧版本升级**：截图键曾默认 `F1`、贴图剪贴板曾默认 `F3`。全局占用这两个键会让前台程序
> 再也收不到它们（`F1` 是常见帮助键、`F3` 是"查找下一个"），所以默认值已改为 `Ctrl+Shift+A`
> 与 `Ctrl+Alt+Z`。**仍在用旧默认值的配置会在首次启动时自动迁移**；如果你当年手动改过键位，
> 则保持不动。想改回或换成别的键：设置 → 快捷键。

### 2.2 遮罩内按键（截图时）

| 按键 | 动作 | 说明 |
|---|---|---|
| `Enter` | 确认截图 | 按「截图」分组里的开关执行复制/保存/贴图 |
| `Esc` | 取消截图 | 不产生任何结果 |
| `Ctrl+C` | 复制 | 只复制，忽略其它开关，并结束本次截图 |
| `Ctrl+S` | 保存 | 只保存，忽略其它开关，并结束本次截图 |
| `F3` | 直接贴图 | 不进剪贴板、不落盘 |
| `T` | 标注 | 打开标注编辑器 |
| `Tab` | 切换元素检测候选 | 由内向外：按钮 → 面板 → 窗口 |
| `C` | 取色并复制 | 取光标像素，按设置的表示法复制并记入历史 |

遮罩里的**固定交互**（不可改键）：

- `方向键` 平移 1 像素、`Shift+方向键` 10 像素、`Ctrl+方向键` 改选区大小；
- **按住 `Shift` 拖动 = 正方形**；抓住四角手柄时按住 `Shift` = **等比缩放**（保持原宽高比）；
- 拖动 8 个手柄缩放选区；鼠标旁有放大镜与像素坐标/尺寸提示；
- **双击左键** = 确认；**右键** = 取消。

> 遮罩顶部的提示条会把上面这些键位（拖动框选 / 单击选中元素 / 方向键微调 / `Shift` 正方形 /
> `T` 标注 / `C` 取色 / `Enter` 确认截图 / `F3` 直接贴图 / `Esc` 取消截图）一次列全，
> 窄屏上自动折行；改键后提示条跟着变。

> **关于"遮罩期间让位"**：如果某个全局热键与上表里的键**撞键**（系统级注册会独占按键，
> 让遮罩收不到），WhSnap 会在遮罩出现前**临时注销那个全局热键**、遮罩结束（含进标注到标注结束）
> 后**按原键位恢复**。所以你给全局动作和遮罩动作绑同一个键是安全的，不会出现"提示说按了有用、
> 实际没反应"。若恢复时那个键已被别的程序抢走，会在日志里明确告警并在设置页显示冲突状态。

### 2.4 贴图窗口内按键

| 按键 | 动作 | 按键 | 动作 |
|---|---|---|---|
| `Ctrl+C` | 复制到剪贴板（原始像素） | `0` | 恢复 100% |
| `Ctrl+S` | 另存为… | `Shift+T` | 切换缩略图模式 |

> 缩略图键默认是 `Shift+T` 而不是 `T`：`T` 在遮罩里是"标注"、在标注编辑器里是"文字工具"，
> 而贴图 → 标注是连续操作，同一个键三种含义必然按错（旧配置里仍是 `T` 的会在首次启动时自动迁移）。

- `滚轮` 缩放（步进见设置）；`Ctrl+滚轮` 调不透明度 ±5%，`Ctrl+Shift+滚轮` ±20%；
- 拖动移动；`双击` 隐藏；`Shift+双击` 切缩略图；`Esc` 隐藏；`方向键` 微调位置、`+ / -` 缩放；
- **右键** 打开菜单（复制 / 另存为 / 标注 / 缩放 / 旋转翻转 / 缩略图 / 不透明度 20–100% / 穿透 / 隐藏 / 关闭 / 批量操作），
  菜单里 12 个可改键动作**都带当前键位列**（改键后菜单跟着变）。

## 4. 操作指南

### 4.1 截图

1. `Ctrl+Shift+A`（或托盘「截图（区域）」）→ 屏幕冻结并弹出遮罩；
2. 拖动框选（按住 `Shift` 拖出正方形）；鼠标旁显示放大镜、像素坐标与尺寸；
3. 精修：`方向键`（`Shift` ×10）、拖 8 个手柄（按住 `Shift` 等比）、拖选区内部整体移动；
4. 确认：
   - `Enter` → 按设置执行复制 / 保存 / 贴图；
   - `Ctrl+C` / `Ctrl+S` / `F3` → 只复制 / 只保存 / 只贴图；
   - 需要标注就先按 `T`，画完再确认。

托盘气泡会回报结果（"已复制到剪贴板；已保存 …"）。

### 4.2 元素检测（不用手画，直接选中界面元素）

遮罩显示时，光标下的界面元素会被自动高亮：

- **悬停**即高亮"最小的那个元素"；
- **单击**直接选中该元素（不用拖）；
- `Tab` 在候选之间由内向外切换（按钮 → 面板 → 窗口）；
- 拖动超过 4 像素即放弃元素吸附，变回普通框选，两者互不干扰。

识别不到时（老程序、UWP 边界、UIA 超时）会退回"顶层窗口矩形"。可在设置里关掉元素检测，或只关 UI Automation 提速。

### 4.3 取色器与颜色历史

- 遮罩里按 `C`：取光标所在像素的颜色，按设置的表示法复制到剪贴板，并记入颜色历史；
- 托盘「取色器（取色并复制）」：不进截图流程，点一下即取色；
- 历史最多保留"颜色历史条数"条，自动去重；遮罩左下角显示最近 12 个色块；
- 托盘「最近颜色」子菜单可再次复制任意历史色，也能「清空颜色历史」。

### 4.4 标注

- 入口：遮罩里框选后按 `T`，或贴图上按 `Space`（或右键菜单「贴图内标注」）；
- 13 种工具：选择/移动、矩形、椭圆、直线、箭头、铅笔、马克笔、文字、马赛克、模糊、橡皮擦、序号、高亮；
- 样式：颜色（`1`–`8` 或工具栏色块）、线宽（`[` `]` 或工具栏）、填充不透明度、字号；
- `Ctrl+Z` / `Ctrl+Y` 撤销重做（按图元命令栈，不是位图快照）；
- **二次编辑**：切到「选择」工具点中已有图元 → 拖动移动、拖角缩放、双击文字改内容，`Delete` 删除；
- **马赛克/模糊作用于当前可见画面**（含你已画的图元），**橡皮擦只擦标注层**，底图不会被打洞；
- 工具栏「复制」= 只复制；「确认标注 (Enter)」= 按设置走复制/保存/贴图；
- 导出严格 1:1：结果与选区同尺寸同像素；
- 标注回写贴图：从贴图进入标注时，确认后贴图内容就地更新。

### 4.5 贴图

- 来源：截图确认时贴图、`Ctrl+Alt+Z` 贴剪贴板、托盘「贴图剪贴板内容」、开启「复制即贴图」后复制即贴；
- 支持内容：图像、文件（图片按图贴、其它渲染成文件卡片）、文本、HTML（纯文本）、颜色值；
- 每个贴图都是**原生分层窗口**：透明处鼠标自动穿透，几乎不占内存（30 张约 53 MB）；
- 全部操作见 §2.4 与右键菜单；
- **管理面板**：托盘「贴图管理…（N 张）」→ 列出每张的尺寸/位置/状态，可逐张置顶、显示/隐藏、关闭，也能批量；
- **备份与恢复**：默认自动备份（去抖 5 秒），崩溃或重启后按「启动时恢复上次贴图」恢复；备份在 `%APPDATA%\WhSnap\pins`；托盘「打开贴图备份目录」可查看，「清理贴图备份」可手动清空（设置 → 维护页也有）。

## 5. 疑难排查

| 症状 | 原因 / 处理 |
|---|---|
| **热键按了没反应** | 多半被别的软件占用（输入法、录屏、微信/QQ 截图、Snipaste）。设置 → 快捷键 → 顶部的冲突横幅会写明是「和别的动作冲突」还是「被系统里的其它程序占用」，并给出**疑似占用者**（如 Snipaste / QQ 截图）；点横幅上的「改绑」就能换键，或换掉占用方。**本机实测**：装着 Snipaste 时 `F3` 与 `Shift+F3` 都被占用，`Ctrl+Shift+A` / `Ctrl+Alt+Z` 可用 |
| **抓不到某个窗口的内容（一片黑）** | 受保护内容（DRM 视频、部分银行/密码界面、UWP 受保护层）系统层面禁止抓取；换 GDI 后端有时能抓到普通区域，但受保护层没有通用办法 |
| **HDR 屏截图偏灰** | WGC/DXGI 只处理 BGRA8，10-bit/HDR 输出会被系统降级；现象是颜色偏灰。临时办法：关闭系统 HDR，或把采集后端固定为 GDI 对比 |
| **休眠/唤醒后热键失效** | 程序监听了 `WM_POWERBROADCAST` 会自动重注册；若仍失效，托盘「设置…」→ 检测热键占用 看是否被别的进程抢走，或重启程序 |
| **双屏/混合缩放比下贴图错位** | 坐标一律按物理像素处理；仍有问题时把显示器拓扑（设置 → 维护 → 导出诊断包里有）发我 |
| **复制图片后粘贴是空白** | 个别程序只认某一种剪贴板格式；WhSnap 同时写 DIB 与 PNG 两种。若目标程序仍粘贴失败，先用「另存为」落盘再用 |
| **贴图点不动** | 多半开了鼠标穿透（`P` 或右键菜单）：用托盘「贴图管理…」→ 关闭穿透，或直接关闭该贴图 |
| **找不到贴图了** | 双击会**隐藏**而不是关闭：托盘「显示全部贴图」（`Shift+F3`）或管理面板 |
| **程序起不来 / 一点就退** | 看 `%APPDATA%\WhSnap\logs` 最新日志；还能用命令行取证：`WhSnap.exe --diagnostics-pack`（程序起不来也能出包） |
| **配置改坏了** | 设置 → 恢复默认；或删掉 `%APPDATA%\WhSnap\settings.json` 后重启（会自动生成默认配置）；损坏时程序也会自动退回默认值并提示 |
| **开机自启失效** | 设置 → 系统 → 开机自启 关掉再打开；若程序不在 `%LOCALAPPDATA%\Programs\WhSnap`（比如开发目录直接跑），程序**不会**替你写注册表 |

## 6. 出问题了怎么给我证据

### 6.1 一键诊断包

三个入口，出来的包结构完全一样：

1. 托盘「**导出诊断包…**」；
2. 设置 → 维护 → 「**导出诊断包…**」；
3. 命令行（程序界面起不来时用）：

```powershell
& "$env:LOCALAPPDATA\Programs\WhSnap\WhSnap.exe" --diagnostics-pack
# 想指定输出目录：--diagnostics-pack --out D:\temp
```

默认输出到 `%APPDATA%\WhSnap\diagnostics\WhSnap-diagnostics-<版本>-<时间>.zip`。

**包里有什么**：`README.txt`（隐私声明）、`report.txt`（版本/进程/路径）、`monitors.txt`（显示器拓扑）、
`hotkeys.txt`（生效热键表）、`settings.json`（当前配置）、`performance.txt`（四项性能实测）、
`crashes.txt` + `crashes/`（崩溃清单与报告原文）、`logs/`（最新日志，截断到最近 2000 行）。

**包里没有什么**：不含剪贴板内容、不含任何凭据（本程序不保存凭据）；
所有文本里的用户目录都已替换成 `%USERPROFILE%`。

### 6.2 崩溃证据

程序崩溃时会自动在 `%APPDATA%\WhSnap\dumps\` 写入：

- `crash-<时间戳>.txt`：脱敏文本报告（版本、来源、异常类型/消息/堆栈、最近 40 行日志）；
- `crash-<时间戳>.dmp`：minidump（约 1 MB 量级，用 Visual Studio / WinDbg 可打开）；
- 下次启动会弹**一次**气泡提醒你（读过就不再提醒），最多保留最近 5 份。

崩溃的 `.dmp` 体积较大，默认不打进诊断包，`crashes.txt` 里会写它的路径——需要时单独发给我。

### 6.3 性能数据

`performance.json` 与诊断包里的 `performance.txt` 记录了四项实测值：热键 → 遮罩可交互、
遮罩内鼠标跟随、确认 → 剪贴板可粘贴（4K）、冷启动 → 托盘就绪。也是自动采样的，不需要你做什么。

## 7. 更新

| 入口 | 行为 |
|---|---|
| 启动后自动检查 | 启动约 4 秒后在后台读一次清单；**不阻塞界面**，失败只写日志，发现新版本才弹气泡 |
| 托盘「检查更新…」 | 手动检查，一定回报结果（发现新版本 / 已是最新 / 具体失败原因） |
| 设置 → 维护 | 显示当前版本、更新通道、清单来源，带「检查更新」与「下载并安装」 |

- 通道：**稳定版（stable）** 只接受正式版；**测试版（beta）** 同时接受预览版；
- 打开「发现新版本时自动下载」后：下载到临时目录 → **校验 SHA-256**（对不上就删除并拒绝安装）→ 弹窗问你是否现在安装 → 是则**先退出 WhSnap** 再静默运行安装包；
- 不想联网就把「启动时检查更新」关掉，程序不会再做任何网络请求；
- 想在没有 Release 的情况下试一遍：把「更新清单地址」指向本地目录里的 `update.json`（`Url` 也填本地安装包路径），点托盘「检查更新…」即可。

## 8. 卸载与彻底清理

1. **设置 → 应用 → 已安装的应用 → WhSnap → 卸载**（或开始菜单「卸载 WhSnap」，或 `%LOCALAPPDATA%\Programs\WhSnap\unins000.exe`）；
2. 卸载时会问 **是否保留配置与日志**：默认「是」（重新安装后设置、颜色历史、日志都还在）；
3. 想连用户数据一起删：
   - 交互式：在确认框里选「否」；
   - 静默：`unins000.exe /VERYSILENT /DELUSERDATA`（不加 `/DELUSERDATA` 时静默卸载**默认保留**用户数据）。

卸载会清掉：安装目录、开始菜单项、`HKCU\...\Run` 里的自启项、控制面板卸载项。想手动彻底清干净，删掉 `%APPDATA%\WhSnap` 即可。

## 9. 已知限制（有意不做）

录屏 / GIF、云同步与账号、在线图床上传、PDF/文档标注、OCR、进程注入、便携模式、Win7/8 兼容、macOS/Linux。

另外两条诚实说明：

- 自签名证书**不会**消除 SmartScreen 警告，也不会显著降低杀软误报；它的收益只是显示发布者名称；
- 双屏混合 DPI 的"鼠标捕获跨屏移交"目前只在合成拓扑上验证过，尚未在真实双屏机上 100 次回归。

### 10.2 命令行开关（排障用）

| 命令 | 作用 |
|---|---|
| `--selftest` | 全链路自检（抓屏、热键、剪贴板、配置、崩溃证据、诊断包、性能埋点…），报告 `%TEMP%\whsnap-selftest.txt` |
| `--diagnostics-pack [--out <目录>]` | 命令行导出诊断包（界面起不来时用） |
| `--update-test` | 更新链路自检（本地传输，不需要联网） |
| `--crash-test [--with-dump]` | 崩溃证据自检；`--with-dump` 会真写一份 minidump 校验后删除 |
| `--power-test` | 睡眠/唤醒后热键重注册自检（8 项：重注册后热键仍生效、按键仍能派发…），报告 `%TEMP%\whsnap-power-test.txt` |
| `--ux-test` | **体验护栏自检**（9 项：默认键真能注册、按键真能派发到动作、改键后全部文案跟随、无跨作用域抢占、无一键多义、容量/引导一致…），报告 `%TEMP%\whsnap-ux-test.txt` |
| `--focal-test` | Focal 设计一致性（令牌 / 度量 / 图标 / 对比度红线 / 界面零字面量色值） |
| `--focal-shots [--out <目录>]` | 把令牌表 / 组件层 / 图标集渲染成 PNG，用于与视觉稿对照 |
| `--onboarding-preview` | 只打开首次运行向导，用于目视验收（不读也不写配置） |
| `--capture-to <png> [--backend wgc\|dxgi\|gdi]` | 单后端抓一张图并输出诊断 |
| `--overlay-test` / `--pin-test` / `--settings-test` / `--annotate-test` / `--element-test` | 各子系统无界面自检 |

退出码 `0` = 通过。想更省事：直接看设置 → 维护页的运行状态与更新结论。
