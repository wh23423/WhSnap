# ADR 0004：HTML 贴图只提取纯文本，不引入渲染引擎

- 状态：已采纳（M2）
- 日期：2026-10-15

## 背景

Snipaste 支持把网页上复制的内容贴成"带排版的图"。要做到等价效果，需要 HTML 排版引擎：
要么嵌 IE/`WebBrowser`（已废弃、有攻击面、渲染与浏览器不一致），
要么引入 WebView2（运行时体积 + 依赖 + 首屏加载 + 进程模型）。

## 决策

**只做纯文本提取**（`HtmlText.ExtractPlainText`）：取 `<!--StartFragment-->` 分片、把块级标签与 `<br>` 换成换行、
去标签、解实体（含 `&#xNNNN;` 数值实体）、折叠多余空行，然后用与纯文本相同的渲染器贴图。

## 代价与后果

- 表格/样式/图片会丢失，网页复制的内容"能看到字，但不还原排版"。
- 换来：零额外依赖、零攻击面、贴图速度与纯文本一致。README 的"已知限制"里写明这一点。
- 如果以后真有强烈需求，可以单独做"HTML → XAML 子集转换"，仍然不引渲染引擎。

## 重新评估的时机

自己或小圈子成员真的经常需要贴"带排版"的网页内容时（目前判断：不需要）。
