# ADR 0007：自签名证书分发（不采购 OV/EV）

- 状态：已采纳（M0）
- 日期：2026-10-15

## 背景

发布对象是**自己 + 小圈子**（决策 D11），不是陌生人分发。
代码签名证书的选项：自签名（免费）、OV（约 200–400 美元/年）、EV（更贵，需硬件令牌 + 资质审核）。

## 决策

用 `New-SelfSignedCertificate` 生成代码签名证书，签名脚本 + 信任导入脚本随包分发。
**诚实写清局限**：自签名不会消除 SmartScreen 提示，也基本不降低杀软误报；
它的实际收益是文件属性页显示发布者、对方导入信任后不再提示"未知发布者"、以及签名+时间戳证明文件未被篡改。

## 代价与后果

- 每位小圈子成员需要一次性"导入信任"（管理员权限，一次即可，`install-trust.ps1`）。
- 私钥 `.pfx` **绝不入库**（`.gitignore` 强制），CI 用 GitHub Secrets 注入。
- 如果将来面向陌生人分发，需要重新评估 OV/EV（backlog 里记着）。

## 重新评估的时机

分发对象扩大到陌生人，或杀软误报开始影响使用。
