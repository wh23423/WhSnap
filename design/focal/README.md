# Focal · WhSnap 前端设计规范 v1.0

一套为 **WhSnap**（Windows 截图 / 贴图工具）重新设计的界面语言。
**这是一个设计交付包**：一份规范 + 六个高保真视觉稿 + 一张令牌表。代码由实现方按此实现。

**核心命题**：截图工具永远不拥有背景 —— 遮罩浮在任意桌面内容之上，放大镜要读出单个物理像素。
这条约束决定了整套语言是 **dark-first** 的，并且全局只有一个交互色。

## 三、给实现方的两张表

- **[`tokens.css`](tokens.css)** —— 唯一色值 / 字号 / 间距 / 圆角 / 层级变量。实现方只需要读这一个文件，
  规则是：**界面代码里不允许出现字面量色值**，只允许引用令牌。
- **[`focal.css`](focal.css)** —— 组件层（`f-` 通用 · `ov-` 遮罩 · `an-` 标注 · `ob-` 向导 · `spec-` 文档页），
  可作为命名与结构参考；视觉稿的所有状态（默认 / 悬停 / 按下 / 选中 / 禁用 / 录制中）都在这里。

## 六条不会破例的规则

1. **一个颜色做全部交互。** Signal Amber `#F5A524` 只做填充 / 描边 / 焦点环 / 量测标记；
   浅底要写小字时换 `#8A5A0A`（5.4:1）或"琥珀底 + 墨字"。`#F5A524` 压白底只有 2.0:1 —— **禁止用于文字**。
2. **暗色优先，纸色阅读。** 遮罩与工具条是暗的（浮在别人的画面上），设置与文档是纸色的。
3. **阴影只属于"浮在不可控内容之上"的面。** 按钮、卡片、列表行、文字永远没有阴影。
4. **圆的是"读的"，方的是"点的"。** 全圆只给状态与连续量（状态点、状态胶囊、开关、滑杆握把）；
   动作与容器一律 6 / 10 / 14。CTA 绝不用胶囊。
5. **数字一律等宽。** 坐标、尺寸、色值、百分比、快捷键走 Cascadia Code + tabular-nums。
6. **面积优先于描边。** 先换表面色阶，再加线。可见的 1px 线越少，越像仪器。

## 未完成 / 边界

- 视觉稿是**静态高保真稿**：悬停、按下、录制中、禁用等状态都在 CSS 里定义且可在浏览器里验证，
  但没有做真实交互逻辑（没有 JS 行为），这是实现方的工作。
- 托盘菜单是 WinForms 原生菜单，本包只给出设计规格；落地需要自绘 `ToolStripRenderer`。
- 深浅主题只覆盖两种**场景**（暗色操作面 / 纸色阅读面），没做同场景双主题切换 —— 桌面工具不需要：
  遮罩本身就是暗的。
- 其余见 [`DESIGN.md`](DESIGN.md) 第 12 节。
